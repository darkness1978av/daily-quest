# הרפתקת היום (גרסה 2)

אפליקציית שגרת בוקר ולילה לילד או ילדה עם ADHD. עברית בלבד, PWA.

- כניסה עם מייל וסיסמה (Supabase), משפחה עם קוד הזמנה לכל תפקיד.
- הגדרה ראשונה: מגדר, שם, דמות, חיית מחמד (כולל הכלב).
- שתי שגרות (בוקר, לילה), עולם ההצלחות (תגים ומדבקות), מצב הורים.
- הגדרת Supabase: להריץ פעם אחת את `supabase/mq-setup.sql` ב-SQL Editor.
- פיתוח: `npm install` ואז `npm run dev`. בנייה: `npm run build`.
